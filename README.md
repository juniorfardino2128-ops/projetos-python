# Sistema de Controle de Estoque

## Sobre o projeto
Projeto independente desenvolvido em Python durante meus estudos e prática de programação.

O objetivo é simular o controle de estoque de uma loja, permitindo gerenciar produtos por meio de um menu interativo.

## Funcionalidades
- Cadastro de produtos.
- Verificação de códigos duplicados.
- Listagem de produtos cadastrados.
- Consulta de produtos pelo código.
- Atualização de quantidades.
- Remoção de produtos.

## Tecnologias e conceitos utilizados
- Python
- Dicionários
- Funções
- Estruturas condicionais
- Laços de repetição
- Entrada e validação de dados

## Aprendizado
Projeto desenvolvido como prática de lógica de programação e construção de sistemas em Python.

# Batendo Meta de Venda

## Sobre o projeto

Projeto independente desenvolvido em Python durante meus estudos e prática de programação.

O objetivo é verificar quais vendedores atingiram a meta de vendas estabelecida em R$ 50.000,00, comparando os valores vendidos por cada vendedor com a meta definida.

## Funcionalidades

- Definição de uma meta de vendas.
- Armazenamento dos nomes dos vendedores e seus respectivos valores de vendas.
- Verificação dos resultados utilizando estruturas condicionais.
- Identificação dos vendedores que atingiram a meta.
- Exibição dos resultados no terminal.

## Tecnologias e conceitos utilizados

- Python
- Listas
- Tuplas
- Laço de repetição `for`
- Estrutura condicional `if`
- Comparação de valores
- Formatação de texto com `format()`

## Aprendizados

Prática de estruturas de repetição, condicionais e organização de dados em Python para análise de resultados de vendas.
