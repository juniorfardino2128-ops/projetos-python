# Sistema de Controle de Estoque

## Sobre o projeto
Projeto independente desenvolvido em Python durante meus estudos e prática de programação.

O objetivo é simular o controle de estoque de uma loja, permitindo gerenciar produtos por meio de um menu interativo.

## Funcionalidades
- Cadastro de produtos.
- Verificação de códigos duplicados.
- Listagem de produtos cadastrados.
- Consulta de produtos pelo código.
- Atualização de quantidades.
- Remoção de produtos.

## Tecnologias e conceitos utilizados
- Python
- Dicionários
- Funções
- Estruturas condicionais
- Laços de repetição
- Entrada e validação de dados

## Aprendizado
Projeto desenvolvido como prática de lógica de programação e construção de sistemas em Python.
